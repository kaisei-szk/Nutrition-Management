# データ記録

`records/` のCSVが本人の実記録を保存する正本です。GitHub上のリポジトリが `Private` であることを確認してから入力し、Gitで履歴管理します。初期状態はヘッダーだけで、実データは含まれていません。

`templates/` のCSVは列定義と架空サンプルを示す参照用ファイルです。サンプルの日付は実在の記録と区別するため `2099-01-01` とし、`is_sample=true` を付けています。

## 共通ルール

- 文字コード: UTF-8
- 区切り文字: カンマ
- 日付: `YYYY-MM-DD`
- 真偽値: `true` / `false`
- 金額: 日本円の整数
- 数値が不明な場合: 空欄
- カンマや改行を含む文字列: ダブルクォートで囲む

## ファイルの役割

| 記録ファイル | 1行の単位 | 主な用途 |
| --- | --- | --- |
| `records/weight.csv` | 1回の計測 | 毎日の体重 |
| `records/meals.csv` | 1食 | 食事内容、カロリー、タンパク質 |
| `records/exercise.csv` | 1回の運動 | 種類、時間、距離、推定消費量 |
| `records/expenses.csv` | 1件の支出 | 自炊費と外食費の分離 |

`expenses.csv` の `budget_scope` は、自炊予算に含める支出を `home_cooking`、含めない外食を `excluded` とします。食事CSVの金額はその食事の参考値で、予算集計の正本は支出CSVです。

`is_sample` は参照テンプレートとの列互換性を保つため記録ファイルにも残します。本人の実記録は `false` とします。

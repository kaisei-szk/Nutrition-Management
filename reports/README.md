# 集計レポート

週次・月次テンプレートは、摂取カロリー、タンパク質、体重、運動、自炊費を定期的に振り返るために使います。

実データを含む完成レポートは `reports/generated/` に保存し、Privateリポジトリ内でGit管理します。実データ入りレポートを追加する前に、GitHub上の可視性が `Private` であることを確認してください。テンプレートを変更する場合は `weekly/TEMPLATE.md` または `monthly/TEMPLATE.md` を更新します。

自炊費には `budget_scope=home_cooking` の支出だけを含め、`budget_scope=excluded` の外食費は別欄に記録します。
